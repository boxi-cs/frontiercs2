FrontierCS 2 · Open Course

Computer Science R&D, task by task

Designed by Boxi Yu

FrontierCS 2 asks AI agents to do CS research. Each task removes the key contribution of a paper from the code released with it, and an agent must write it back and beat the authors' version on every metric. This course takes the 48 tasks one field at a time: what each paper found, what the task removed, how it is judged, and what the agents wrote. Every idea comes with a small model you can run in your browser.
